# Output files

Set the collection directory with `dump -o DIR`; the default is `./dump`.
Files are produced only when the corresponding APIs or events are observed.
Not every session produces every artifact.

## Start here

| File | Contents |
|---|---|
| `report.html` | Browser-readable report generated by `report` |
| `report.json` | Analysis results generated by `analyze` |
| `ios_app.json` | iOS bundle ID, version, and module inventory |
| `http_traffic.json` | HTTP observations; iOS captures URLs and methods only |
| `sqlite_log.json` / `fileio_log.json` | SQL and file operations |

Run `analyze DIR` before `report DIR`.
See [Command reference](subcommands.md) for custom output paths.

## Binaries and game assets

| File | Contents |
|---|---|
| `classes_N_*.dex` / `dex_obfuscation_report.json` | Android DEX files and obfuscation information |
| `libil2cpp.so` / `UnityFramework` / `*.dylib` | IL2CPP and other memory images; names depend on the OS and module |
| `global-metadata.dat` / `il2cpp_dump.json` | IL2CPP metadata and symbol map |
| `*.dll` / `asset_*.unity3d` | Mono DLLs and Unity AssetBundles |
| `dlopen_*` | Memory images of libraries loaded after attachment |
| `ue4_sdk.json` / `ue4_pak_list.json` / `ue4_pak_*.pak` | Android UE4 SDK and PAK artifacts |
| `ue4_blueprint_trace.json` | Android UE4 Blueprint calls |

Memory images may differ from the original files and are not necessarily executable or suitable for resigning.

## Events and details

| File | Contents |
|---|---|
| `crypto_keys.json` / `rsa_private_key.der` | Cryptographic observations; CommonCrypto on iOS |
| `tls_connections.json` | Android TLS SNI hostnames |
| `jni_map.json` | Android JNI mappings |
| `heap_*.json` | Android Java heap keys, strings, preferences, and other data |
| `websocket_log.json` / `protobuf_log.json` / `binder_log.json` | Android networking and IPC |
| `dlopen_log.json` / `dlsym_log.json` | Library loading and symbol resolution |
| `coverage.json` / `trace.json` | Code coverage and function calls |
| `anti_tamper_log.json` / `safetynet_log.json` | Android integrity and attestation-related events |

The HTML report does not display every raw event. Inspect the original JSON files for details.
